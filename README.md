# SpectreAudit 🔍 | Neural Visual Dataset Intelligence

SpectreAudit is a production-grade visual dataset evaluator with a James Bond-style intelligence interface. It uses Google's **Gemini 2.5 Flash** (Vision & TTS) to audit batches of images for design integrity, professional standards, and dataset purity.

![LensAudit Showcase](https://images.unsplash.com/photo-1551288049-bebda4e38f71?auto=format&fit=crop&q=80&w=1200)

## 🌟 Key Features

### 🧠 Neural Evaluation Engine
- **Visual Hierarchy**: Detects focal points and information flow.
- **Readability Analysis**: High-fidelity OCR and contrast checking.
- **Layout Balance**: Analyzes grid alignment and spatial distribution.
- **Logic Reasoning**: Provides a textual explanation for every score.

### 🛡️ Semantic Filtering
Automatically purges the following "noise" categories:
- **Memes**: Social media content and high-impact font overlays.
- **Ads**: Commercial banners and marketing call-to-actions.
- **Clutter**: Low-semantic-value visuals or chaotic screenshots.
- **Low-Res**: Assets that fail minimum fidelity thresholds.

### 🎨 Design System
- **Bento Grid Dashboard**: A dark-themed, high-density interface built for modern workflows.
- **Audio Guide**: Integrated Text-to-Speech narration to walk you through the system.
- **Motion Orchestration**: Staggered layout animations for smooth data visualization.
